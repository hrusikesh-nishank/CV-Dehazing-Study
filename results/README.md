# Results

Everything the report is built from. All numbers were produced by the code in this repository on one RTX 5060 Ti (November 2026).

```
results/
├── quick_report.md        all comparison tables with 95 % bootstrap intervals (generated by quick_report.py)
├── tables.tex             LaTeX tables generated by make_tables.py
├── plan.json              iterations per model chosen by quick.py from the measured speeds
├── timing/                speed probes (it/s, memory, time split data / synthesis / network)
├── per_run/<run>/         one folder per evaluated model
│   ├── OHAZE.csv, NHHAZE.csv, DENSE.csv   per-image PSNR and SSIM
│   ├── summary.json                        mean PSNR / SSIM per test set
│   ├── rtts.json                           RTTS mAP50 and no-reference metrics (where evaluated)
│   └── train_log.txt, args.json            training log and exact arguments (trained runs only)
├── figures/               report figures, qualitative comparisons, synthesis grids
├── logs/                  preflight, realism check and (V, A) draw statistics for each calibration
└── queues_run/            the exact command lists that produced these results
```

## Run names

`<model>__<arm>[_<tag>]_s<seed>` for models trained here, `pre__<name>` for published models evaluated as released.

| Part | Meaning |
|---|---|
| model | `dehazeformer-t`, `gunet-t` (trained from scratch); `dehazeformer-b`, `deanet` with tag `ft` (fine-tuned from the official RESIDE-OTS weights) |
| arm | B0, N0, R0, R1, R2, R3, R3N, H, R3H (see the main README) |
| tag | `uncal` (no calibration), `rtts` (calibrated on RTTS only), `ft` (fine-tuned) |
| seed | 0, 1, 2 |
| `pre__…` | hazy input, DCP, official DehazeFormer-T/B (OTS), official DEA-Net (OTS), HazeFlow (published RTTS outputs only) |

RTTS was evaluated for the published models and the first quick-protocol runs only. The later control runs report the paired sets only, because RTTS detection did not separate the methods.
